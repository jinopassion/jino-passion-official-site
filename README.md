# JINO PASSION 公式サイト

静的なHTML・CSS・JavaScriptで作成したトップページです。公開対象のファイルは `public/` 内にあります。ビルドや有料サービスは不要です。

## ローカル表示

```sh
cd public
python3 -m http.server 8765
```

ブラウザで `http://127.0.0.1:8765/` を開いてください。

## GitHubとCloudflare Pages

公開用GitHubリポジトリ: https://github.com/jinopassion/jino-passion-official-site

Cloudflare Pagesでこのリポジトリを連携し、次のように設定します。

| 項目 | 設定 |
| --- | --- |
| フレームワークプリセット | なし |
| 本番ブランチ | `main` |
| ビルドコマンド | `exit 0` |
| ビルド出力ディレクトリ | `public` |

Cloudflare Pagesの公式案内: https://developers.cloudflare.com/pages/framework-guides/deploy-anything/

## コンテンツの状態

- 現在はトップページのみです。残りのページは内容の確認後に追加します。
- トップページの「料金」から、施設向けと個人宅向けの料金を切り替えて表示できます。区分ボタンは料金見出しの直下にあり、PC・スマートフォンのどちらでも押すと対象の一覧が開きます。施設向けは `訪問美容サービス3.pdf` の6ページ、個人宅向けはユーザーが用途を指定した `　個人宅用.pdf` を参照しました。個人宅向け資料には税込・出張費の記載がないため、サイトにも付記していません。両方の料金体系と条件が現行の正式案内か、公開後も確認してください。
- JPエンブレムは、ユーザー指定の `名刺表2.pdf` の表面から切り出した画像です。文字ロゴは名刺の表記を参考に組版しています。
- ヒーローと訪問美容欄の画像は、参考画像の構図・質感をもとに新しく生成したコンセプト写真です。実際の施術・お客様・使用器具の記録写真ではありません。参考ブランドの画像やロゴは使用していません。
- 電話番号は名刺資料・サービス資料に記載された番号です。現行の窓口か、公開後も確認してください。
- お問い合わせ欄には、2026-11-24にユーザーが新しく提供した公式LINEのQR画像を使用しています。QRから読み取った `https://lin.ee/Sv0eDUF` をスマートフォン用のリンクにも設定しています。名刺裏PDFの旧QRコードは使用していません。
- お問い合わせ欄のメールアドレス `jinopassion.office@gmail.com` は2026-11-24にユーザーが提供したものです。
- 内部用の経営計画PDFなどは公開フォルダに含めていません。
